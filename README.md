# homebrew-tap

Homebrew formulae for my own tools.

```bash
brew install sapn95/tap/git-tidy
```

| Formula                                           | What it is                                                              |
| ------------------------------------------------- | ----------------------------------------------------------------------- |
| [bib](https://github.com/sapn95/browser-in-a-box) | Real, unmanaged browser in a box: a Linux container or a macOS VM       |
| [git-tidy](https://github.com/sapn95/git-tidy)    | Keep a directory full of git checkouts clean: sync, prune, clean, sweep |
| [pfadi](https://github.com/sapn95/pfadi)          | macOS file browser with an address bar you can click into and type      |

Each formula is generated by its own project's release workflow, so the version
and checksums here always match a published release.
